# v0.1.0-pre.6

Pre-release of `Tool.PackageManager`.

## Fixes

- Repair the `bootstrap.ps1` parser regression introduced in `v0.1.0-pre.5`.
- Rebuild development catalog refresh from a clean, known-good bootstrap baseline.
- Refresh `config/bootstrap-plans.json` from `Tool.PackageManager/main` before plan selection by default.
- Keep component installation pinned to the exact coordinated SHAs declared by the refreshed catalog.
- Preserve `-UseBundledCatalog` for explicitly using the catalog shipped with the installed Tool version.
- Block `v0.1.0-pre.5` from the self-update picker.
