# v0.1.0-pre.4

Pre-release of `Tool.PackageManager`.

## Fixes

- Treat a missing pinned Git commit as an expected cache-miss instead of a PowerShell terminating error.
- Fetch an absent exact revision explicitly before checkout.
- Re-verify the fetched revision before detaching to the requested commit.
- Keep orphaned submodule cache reuse and transactional self-update protections from earlier prereleases.
